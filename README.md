# ייִדיקט
## About Us
The **yiddict.app** project seeks to offer a convenient, easy-to-use
dictionary **app** for all speakers and learners of _ייִדיש_.

The motivation for building this project stems from the lack of well-designed
and convenient Yiddish resources _for offline use_.
Other factors are the lack of institutional support for _freely accessible_
tools like these and the lack of encoding standards for data
